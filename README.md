# 🌿 LifeFlow — نظام إدارة الحياة الشخصية المتكامل (Personal Life OS)

> **نظام تشغيل شخصي شامل ومحلي بالكامل (Local-First PWA) يجمع بين إدارة المهام، العادات، التتبع الصحي، الروتينات اليومية، مؤقت التركيز بأصوات طبيعية أوفلاين، خزينة الوثائق المشفرة، صندوق تفريغ الأفكار الذكي باللغة العربية، والمزامنة السحابية الآمنة مع Google Drive.**

## 🏛️ نظرة عامة والمعمارية التقنية

صُمم **LifeFlow** ليعمل وفق فلسفة **Local-First (الأولوية للبيانات المحلية)**، حيث تبقى جميع بياناتك الشخصية ملكاً لك وحدك على جهازك:

- **تخزين محلي فائق السرعة والأمان:** يعتمد على قاعدة بيانات `IndexedDB (v3)` مع 34 متجر بيانات مستقل (`Object Stores`).
- **حماية البيانات من المسح التلقائي:** يتم استدعاء واجهة `navigator.storage.persist()` تلقائياً لضمان عدم قيام المتصفح بحذف البيانات عند امتلاء الذاكرة المؤقتة.
- **تشفير عسكري من طرف إلى طرف:** تشفير متقدم بمعيار `AES-GCM-256` مع اشتقاق المفاتيح بواسطة `PBKDF2` (بـ 210,000 دورة تجزئة مع ملح عشوائي Salt) لحماية الوثائق السرية والنسخ الاحتياطية.
- **مزامنة صامتة وخاصة مع Google Drive:** المزامنة تتم حصرياً داخل مجلد التطبيق الخفي `appDataFolder`، دون طلب أي صلاحيات لقراءة أو تعديل ملفاتك الشخصية الأخرى على Google Drive.
- **تطبيق ويب تقدمي (PWA 100% Offline):** يعمل بكامل طاقته في وضع عدم الاتصال (حتى في وضع الطيران) عبر Service Worker يتبع استراتيجية Cache-First المتقدمة للخطوط والأصوات والأصول البرمجية.
- **محرك صوتي وتنبيهات في الخلفية:** مولد ذبذبات صوتية مبني على `Web Audio API` بالإضافة إلى أصوات ونغمات تنبيه مسجلة ونظام جدولة تنبيهات يعمل في الخلفية ويدعم أزرار الإجراءات السريعة (إنجاز / تأجيل Snooze).
- **محرك معالجة لغة طبيعية عربي محلي (Arabic NLP):** تحليل النصوص العربية وفهم المهام والمواعيد والأولويات والتصنيفات محلياً 100% بدون إرسال أي نص إلى خوادم خارجية.
- **واجهة مستخدم متكيفة بالكامل مع الهواتف (Mobile-First):** شريط تنقل سفلي مرن يراعي المناطق الآمنة للهواتف (Safe Area Insets)، ولوحة أوامر فورية سريعة `Ctrl+K`.

## 💻 التشغيل المحلي السريع

### المتطلبات الأساسية
- تثبيت بيئة [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### الطريقة الأولى: عبر لوحة التحكم السريعة (مستخدمي Windows)
انقر نقراً مزدوجاً على ملف:
```text
run.bat
```
ستظهر لك قائمة خيارات تفاعلية:
- `[1]` تشغيل خادم التطوير السريع (Vite Dev Server) على الرابط: `http://localhost:8000`.
- `[2]` بناء حزمة الإنتاج النهائية في مجلد `dist/`.
- `[3]` معاينة حزمة الإنتاج محلياً ومحاكاة بيئة الإنترنت الحقيقية على الرابط: `http://localhost:4173`.

### الطريقة الثانية: عبر سطر الأوامر (Terminal / PowerShell)
```bash
# 1. تثبيت الحزم (إن لم تكن مثبتة مسبقاً)
npm install

# 2. تشغيل خادم التطوير السريع
npm run dev

# 3. بناء حزمة الإنتاج المضغوطة
npm run build

# 4. معاينة حزمة الإنتاج
npm run preview
```

## 🚀 خطوات النشر السحابي المجاني

يمكنك نشر التطبيق على الإنترنت خلال دقيقتين مجاناً وبشهادة أمان SSL تلقائية عبر أي من المنصات التالية:

### الخيار الأول: النشر عبر Cloudflare Pages (الموصى به - فائق السرعة عالمياً)

#### الطريقة المباشرة (Direct Upload دون الحاجة لـ Git):
1. قم بتشغيل أمر البناء: `npm run build` لتوليد مجلد `dist`.
2. سجّل الدخول إلى [Cloudflare Dashboard](https://dash.cloudflare.com/).
3. توجّه إلى **Compute (Workers & Pages)** > **Pages** > **Create an application**.
4. اختر تبويب **Upload assets**.
5. اكتب اسم المشروع (مثلاً: `lifeflow-app`)، ثم اسحب وأفلت مجلد `dist` كاملاً.
6. اضغط **Deploy site**، وستحصل فوراً على رابط HTTPS مباشر مثل:
   `https://lifeflow-app.pages.dev`

#### طريقة الربط التلقائي مع GitHub:
1. ارفع المشروع إلى مستودع على حسابك في GitHub.
2. في Cloudflare Pages، اختر **Connect to Git** وحدد مستودع `Lifefloww`.
3. اضبط إعدادات البناء كالتالي:
   - **Framework preset:** `Vite`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
4. اضغط **Save and Deploy**. سيتم تحديث موقعك تلقائياً مع كل `git push`.

---

### الخيار الثاني: النشر عبر Vercel

1. ارفع الكود إلى مستودع GitHub الخاص بك.
2. سجّل الدخول إلى [Vercel](https://vercel.com/) واضغط على **Add New Project**.
3. قم باستيراد مستودع `Lifefloww`.
4. سيتعرف Vercel تلقائياً على مشروع Vite:
   - **Build Command:** `vite build`
   - **Output Directory:** `dist`
5. اضغط **Deploy**. سيصبح التطبيق متاحاً خلال ثوانٍ على رابط مجاني مثل:
   `https://lifeflow-app.vercel.app`

## 🔑 ربط Google Cloud للمزامنة السحابية

لتفعيل ميزة مزامنة النسخ الاحتياطية تلقائياً مع Google Drive بحساب المستخدم:

1. افتح [Google Cloud Console](https://console.cloud.google.com/).
2. أنشئ مشروعاً جديداً باسم **LifeFlow**.
3. من القائمة الجانبية، اذهب إلى **APIs & Services** > **Library**.
4. ابحث عن **Google Drive API** واضغط على **Enable (تفعيل)**.
5. توجّه إلى **OAuth consent screen (شاشة موافقة OAuth)**:
   - اختر نوع المستخدم: **External**.
   - أدخل اسم التطبيق: `LifeFlow` وبريد الدعم الخاص بك.
   - في صفحة النطاقات (Scopes)، أضف النطاقات التالية:
     * `https://www.googleapis.com/auth/drive.appdata`
     * `openid`
     * `profile`
     * `email`
   - أضف بريدك الإلكتروني في قائمة **Test Users (المستخدمون التجريبيون)**.
6. توجّه إلى **Credentials** > **Create Credentials** > **OAuth client ID**:
   - Application type: **Web application**.
   - Name: `LifeFlow Web Client`.
   - في خانة **Authorized JavaScript origins**، أضف كلاً من الرابط المحلي ورابط موقعك المنشور:
     * `http://localhost:8000`
     * `https://your-app.pages.dev` (أو رابط Vercel الخاص بك)
7. انسخ **Client ID** المتولد.
8. لتفعيله في التطبيق، لديك طريقتان:
   - **الطريقة السهلة:** افتح التطبيق المنشور، ادخل إلى **الإعدادات (Settings)**، والصق الـ Client ID في خانة "Google Client ID" واضغط حفظ.
   - **أو برمجياً:** افتح ملف `public/google-config.js` والصق المعرف:
     ```javascript
     window.LF_GOOGLE_CLIENT_ID = "YOUR_CLIENT_ID_HERE.apps.googleusercontent.com";
     ```
     ثم أعد البناء والنشر.

## 📱 طريقة تثبيت التطبيق على الهواتف (Android & iOS)

يعمل LifeFlow كتطبيق هاتف أصلي (Standalone Native-like App) بدون أشرطة المتصفح:

### على هواتف Android (Chrome / Edge / Samsung Internet):
1. افتح رابط تطبيقك المنشور عبر متصفح Google Chrome.
2. ستظهر لك نافذة صغيرة في أسفل الشاشة أو زر "تثبيت LifeFlow" داخل التطبيق؛ اضغط عليه.
3. أو اضغط على قائمة الثلاث نقاط `⋮` بأعلى المتصفح، ثم اختر **"تثبيت التطبيق" (Install App)** أو **"إضافة إلى الشاشة الرئيسية" (Add to Home screen)**.
4. سيظهر تطبيق LifeFlow في شاشة هاتفك الرئيسية وقائمة التطبيقات، ويعمل بدون إنترنت تماماً.

### على هواتف iPhone و iPad (Safari):
1. افتح رابط الموقع باستخدام متصفح **Safari**.
2. اضغط على زر المشاركة في أسفل الشاشة (أيقونة المربع الذي يخرج منه سهم للأعلى `⎋`).
3. مرر للأسفل واضغط على **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
4. اضغط على **"إضافة" (Add)** في الزاوية العلوية.
5. سيتم تثبيت الأيقونة على شاشة الآيفون؛ افتحها واستمتع بتجربة تطبيق كامل الشاشة مع إشعارات وتنبيهات خلفية (على iOS 16.4+).

## 🛡️ الخصوصية والأمان
- لا توجد أي خوادم تابعة لجهة خارجية تجمع بياناتك.
- تعمل خزينة الوثائق بتشفير `AES-GCM-256` داخل جهازك عبر `Web Crypto API` المحلية.
- جميع عمليات الـ NLP وتوليد الأصوات والمؤقتات تعمل 100% بدون أي اتصال بالإنترنت.
- المزامنة السحابية اختيارية تماماً وتتصل مباشرة بين متصفحك وسحابة Google Drive الخاصة بك.
